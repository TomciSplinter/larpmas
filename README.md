# LARPMAS

Scroll-animated landing page. Static site, no build step.

- `index.html`: the page (scroll animation drawn on a canvas from the frames)
- `frames/`: 241 JPEG frames of the scroll video (1920×1080)
- `logo.png`: LARPMAS wordmark

Deploy on Vercel: import the repo, framework preset "Other", no build command, output directory `.` (the root).
